元服务改造影响对比 · 自动网络版

快速使用
1. USB 连接手机，开启开发者调试，保持手机解锁亮屏并连接已保存的 Wi-Fi。
2. 打开“ServiceImpact.exe”，填写两个已安装的包名。
3. 在“配置网络环境”中选择“内置网络模拟（自动代理）”，再选择网络预设。
4. 选择冷热启动、仅冷/热启动、随机 Monkey 或组合方式，设置次数、时长和保存目录。
5. 点击“一键对比”。自动备份网络 → 配置代理 → 两组依次测试 → 恢复环境 → 生成并打开报告。

本版免费内置网络模拟，不需要启动 Reqable，不需要 Reqable API 令牌或高级版。
端口自动分配，通过 hdc USB 反向转发连接电脑代理，不需要填写电脑 IP 或修改 Windows 防火墙。
HTTPS 使用 CONNECT 隧道原样转发，不解密内容、不安装 CA 证书、不修改正式应用包。

带宽是经过代理的所有连接合计上限，实际速度还受电脑网络及服务器影响。
延迟在每次新建上游连接时添加，不是逐个业务请求延迟，也不是实测 RTT。
失败按新连接概率模拟，随机种子固定为 42，每组开始重置；不同请求顺序仍可能获得不同失败结果。
这是代理级异常模拟，不是 TCP/IP 数据包丢包模拟；HTTP/2 多路复用或长连接不会按每个请求单独失败。
普通明文 HTTP 每个连接转发一个请求并关闭连接，可能改变连接复用行为；HTTPS 隧道保留原加密协议和长连接。
只覆盖采用手机系统 HTTP 代理的请求，不覆盖绕过代理的原生 Socket、UDP/QUIC 等流量。
“断网”预设仅阻断经过代理的新连接；需要手机实际断网时，选择“手机断网（关闭 Wi-Fi 和数据）”。
3G/4G/5G 是模拟预设，不会改变手机真实通信制式。模拟请求使用电脑网络出口，不代表真实移动网络路由。

其他网络模式
当前网络：只记录，不自动修改。
Wi-Fi：连接已保存 Wi-Fi，关闭移动数据并暂时取消该 Wi-Fi 的代理，结束后恢复。
蜂窝：尝试开启移动数据并关闭 Wi-Fi；要求手机存在可用 SIM 卡。开关不可用或没有网络时停止测试。
手机断网：关闭移动数据与 Wi-Fi，并校验系统无可用网络；若存在其他联网方式而无法确认断网，则停止。
蜂窝模式需要可用 SIM 卡与系统开关支持；不保证所有设备兼容，需在目标机验证。

代理和网络恢复
测试开始前保存 Wi-Fi、移动数据开关及当前 Wi-Fi 代理；结束、停止和普通异常后自动恢复。
关闭窗口会先停止采集并尝试恢复；恢复时也需要手机连接且解锁。
断电、强制结束进程或手机锁屏可能阻止恢复。重新打开工具，连接同一设备，点击“恢复上次环境”。
有未完成的恢复记录时，工具阻止新任务覆盖原记录。
恢复日志：本机 %LOCALAPPDATA%\ServiceImpact\network_recovery.json，以及本次输出目录 network_session.json。
仅恢复工具创建的 USB 转发规则，不删除其他调试转发。
自动代理页面适配已验证的 HarmonyOS 7 中文设置页面；其他系统布局不同会停止，保留恢复记录，不盲点控件。

报告
保留启动、CPU、PSS 内存、包体和系统缓存前后快照，并增加网络预设、阶段快照、代理连接数/字节数和恢复结果。
代理计数包含设备其他应用，无法按包名归因；计数非零不证明所有目标业务都经过代理。
没有观察到代理连接时，报告会提示不能确认模拟覆盖目标业务。
真实包体对比仍需要每组分别提供 APP/HAP 文件；仅有包名不能推导实际分发包大小。
一组失败/用户停止后不继续第二组，已有数据生成部分报告，并明确标记未完成。
正式判断应使用相同场景、相同测试参数和足够样本；仓库不附带真实业务测试数据。
